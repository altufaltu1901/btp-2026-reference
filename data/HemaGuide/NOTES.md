# HemaGuide — data

- **Code:** https://github.com/Friedrich-Lab/HemaGuide (copied to `code/HemaGuide/`).
- **Knowledge base:** built from **Onkopedia** guidelines (public). The repo ships
  `code/HemaGuide/data/` (onkopedia.json, gene_classification.json, entities.txt,
  entity_slugs.json) and `build_kb.py` to construct the vector DB.
- **Clinical decision memory (>2,000 real tumour-board cases):** Heidelberg
  University Hospital patient data — **not released**.
- **Validation sets:** 555 external + 64 prospective cases — **not released**.
- **Supplementary material** from the Nature Medicine paper: download from
  nature.com (institutional access) and drop here.
